**Legend:**
- ✓ = tested/verified
- — = not applicable
- Help = `--help` output exists and is accurate
- Normal = runs successfully with valid input
- Empty = handles empty state (no accounts, no data)
- Error = handles error cases (missing account, invalid input)
- JSON = supports `--json` output
- Docs = documented in README

**Notes:**
- `tu account list` does not support `--json` (known limitation, documented)
- `tu doctor` uses raw ANSI (respects --no-color via noColor variable)
- `tu update` is informational only (prints URL, does not auto-update)
- `tu completion` is auto-generated by Cobra
